## TD-CLOUD-WINDOW-001 — ввод в Order Flow при открытом Cloud

**Состояние:** CLOSED — повторная ручная проверка владельца, 24.09.2026.
**Область:** OsData → Order Flow → «Исследование Cloud», переключение и ввод.

После первоначальных изменений владелец сообщал, что окно Cloud остаётся
поверх Order Flow и мешает вводу. На основании того сообщения запись была
отложена. После коммита `180e830ea65f1b3b2072236e5575fe38c0ffebba`
владелец повторил проверку и сообщил, что всё работает. Поэтому прежняя
жалоба больше не считается открытым дефектом, а временный совет закрывать
Cloud перед изменением входных параметров отменён.

В опубликованном коде Order Flow открывается через `Show()`, Cloud и вынесенным
графикам не назначается WPF `Owner`, а принудительный `Topmost` удалён из
затронутых XAML-окон. Точная причина первоначального наблюдения не установлена;
по исходному сообщению нельзя отдельно доказать, какое изменение его устранило.

Сборка решения и offline-тесты 144/144 в предыдущем коммите проверяли код,
но не ввод в настоящие окна ОС. Основание закрытия этой записи — **повторная
ручная проверка владельца**. Состав дополнительных проверок (OsData, внешнее
приложение, повторное открытие и закрытие окон) не зафиксирован и здесь не
объявляется пройденным.
