# T12. Финальная приёмка и выпуск

Статус: NOT_STARTED. Зависимости: T08,T11; T09/T10 для включённых модулей. Gate: QG12. Требования: все R01–R22 для заявленного профиля.

## Цель

Поставить пользователю проверенный, объяснимый продукт с честным статусом функциональности и исследования, а не только компилирующийся класс.

## Работа

Проверить [трассировку](../11-traceability.md), завершить build/regression, собрать release manifest и gate status. Повторить ручной путь в Tester: выбрать сценарий → увидеть S01/S02 → проверить skip/stop → открыть решения → экспорт → подобрать ограниченные параметры → воспроизвести выбранный pass.

Обновить инструкции кнопками по фактическому UI, сохранить проверенные screenshots. Подключить документацию к project/CONTEXT.md и доменному router, не заменяя прежние материалы. Проверить old settings, выключенный модуль, восстановление/rollback schema.

Провести конечное read-only review архитектуры/математики и безопасности. Нельзя объявлять независимый review при отсутствии отдельного reviewer. Все High/Critical воспроизводимые находки закрыть тестом; нерешённые — BLOCKED.

## Приёмка

Для выбранного TradeOnly/Book/Advanced профиля пройдены обязательные gates, остальные имеют мотивированный N/A либо явно остаются NOT_RUN. Экономический статус Research GO/ResearchOnly/NO-GO отделён от Engineering PASS. Отсутствие преимущества не маскируется победными частичными выходами.

Пользователь подтвердил визуальное поведение обратимого inventory и понятность причин. Live разрешение не подразумевается даже при инженерном выпуске. Нельзя автоматически запускать реальный счёт или MCP stand.

## Поставка

Commit и branch, сборка, тестовые отчёты, run/experiment manifests, capability matrix, формулы/версии, ограничения исполнения, пользовательский quick start, recovery/rollback инструкция и список открытых исследовательских вопросов. Никаких tick datasets, учётных данных или state реального счёта в публичном репозитории.

Форма итогового отчёта: [template](../templates/task-report.md). Поставку считать завершённой только после проверки удалённого commit/ref и отсутствия незаявленных изменений.
