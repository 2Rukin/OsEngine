# T09. OFI и книжные capabilities

Текущий статус: [work record](../evidence/implementation.md#состояние-заданий). Зависимости: T02,T07,T08. Gate: QG09. Требования: R16,R17; дополнительный профиль M3.

## Цель

Добавить реальный расчёт OFI без подмены торговой дельтой и проверить добавочную ценность книги. Источник: SRC-OFI в [13](../13-sources.md); контракты: [04](../04-data-contracts.md).

## Работа

Реализовать формулу en по best bid/ask и размерам. Обрабатывать равенство цен, смену лучшей цены, пустую/перекрещенную книгу, stale data и reset после reconnect. Snapshot-only поток маркировать sampled/proxy.

Подтвердить синхронную подачу trades и quotes в Tester/Optimizer. При отсутствии штатного dual-stream hook добавить минимальный адаптер с отдельным ADR и тестами порядка; не объявлять задачу выполненной по двум несогласованным файлам.

Отдельно оценить современное price impact и потенциальный лаговый сигнал. Использовать только созревшие labels и прошлую калибровку. Внести влияние OFI в политику через версионированное расширение 03: сначала veto/разрешения или масштабы, затем измеренный вклад. Не присваивать коэффициенты по аналогии с чужим рынком.

## Тесты

S23/S24, quote-event fixtures с ручным OFI для всех четырёх индикаторных слагаемых и равных цен, gaps/resets, causal label audit. Отдельно проверить повторное деление на depth: единицы и модель должны исключать ошибочное удвоение нормировки. Зеркальность sign convention относительно d.

## Приёмка

OFI совпадает с эталоном; профиль недоступен без required book; sampled ограничения видны в UI/manifest. OOS ablation показывает эффект отдельно от роста риска/издержек. Если достоверных синхронных данных нет, TradeOnly продолжает работать, а M3 имеет BLOCKED_DATA, не фиктивный PASS.

Артефакты: capability proof, formula tests, calibration report/cutoffs, trace и A4-vs-A3 comparison. Далее [T10](T10-research-execution.md).
