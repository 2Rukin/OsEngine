# T10. Исследовательские модели исполнения

Текущий статус: [work record](../evidence/implementation.md#состояние-заданий). Зависимость: T08; T09 для книжной модели. Gate: QG10. Требование: R21. Режим по умолчанию: выключен / ResearchOnly.

## Цель

Использовать формулы литературы там, где совпадает задача, и измерить их вклад отдельно от target policy. Не выдавать произвольное дробление заявки за Almgren–Chriss или весь APM за точное решение market making.

## Работа

SRC-AS: реализовать reference reservation price и проверку units/направления inventory в исходной модели; адаптированный фьючерсный множитель вывести отдельно. Сопоставить с нашим κ-penalty, не подменяя один другим.

SRC-AC: реализовать reference дискретной траектории (16)–(18) из оригинальной работы, включая корректную связь κ и временного шага, предел κ→0 и численно устойчивые hyperbolic functions. В обычном execution-planner определить момент перепланирования при изменении target и что происходит с уже отправленными остатками. HardStop/cutoff не передавать медленному оптимальному расписанию.

SRC-ADAPT: оценить условный спрос/недоисполнение по прошлому потоку; вручную проверить формулы (4)–(5), условия и допустимую область. Полное воспроизведение оптимальных controls статьи — отдельный research ADR после проверки остальных формул, не автоматическое обещание этой задачи. Если применяется clipping negative demand, обозначить это как нашу модификацию.

## Тесты

Reference arithmetic с независимым вычислением, единицы, φ/κ edge cases, запрет использования будущих c/p, bounded child qty, late fills и terminal override. Сравнение с простым обычным execution на одних target traces; инварианты T05 продолжают выполняться.

## Приёмка

Есть проверяемое соответствие «формула первоисточника → метод → тест → отличие адаптации». Оценены стоимость, задержка и неполное исполнение вне обучающего участка. Увеличение сложности без устойчивого преимущества оставляет модуль выключенным. Недостаток реальных fill/queue данных отражается как ограничение достоверности, а не устраняется оптимистичным симулятором.

Артефакты: research ADR, formulas/calibration report, A5 ablation, перечень включённых/выключенных моделей и оснований. Запуск в live запрещён без QG11/QG12 и отдельного разрешения.
