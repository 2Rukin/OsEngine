## Универсальный контракт работы

До кода: зафиксировать commit базы, прочитать входные документы задачи, проверить действующие вложенные AGENTS.md. При конфликте формулы/метода/статуса не угадывать: записать finding и предложить точечную корректировку ADR. Папку нового робота подтвердить по правилам форка. Не использовать upstream как замену этому репозиторию.

Одна задача — обозримый diff и доказательства. Исполнитель пишет тест до или одновременно с изменением; затем self-review, read-only review архитектуры/математики и безопасности при доступности отдельных reviewers. Не более двух циклов, далее явный BLOCKED. Готовность описывается в [форме отчёта](../templates/task-report.md).

Не переписывать TradeGrid/старые роботы ради удобства интеграции. Не вносить изменения в другие ветки, не rebase/reset/force-push без отдельного разрешения. Разрешение на этот документационный commit/push не является бессрочным разрешением на последующие торговые действия.

Для кода из каталога project: обычная сборка `dotnet build OsEngine/OsEngine.csproj`; при изменениях Tests и перед релизом — `dotnet build OsEngine.sln`. Использовать фактические test commands обнаруженного harness, указать их в отчёте. Не выдумывать существующий путь тестового проекта или число пройденных тестов. MCP stand/live требуют отдельного разрешения пользователя.

## Definition of Done каждого задания

Выполнены все acceptance criteria; имеются commit, фактический список изменённых файлов, build/test results и run manifests; R/S/QG указаны; нет unresolved reachable High/Critical; состояния других задач не объявлены выполненными по косвенным признакам. ResearchOnly — допустимый результат исследовательской задачи, но не скрытый PASS для live.
