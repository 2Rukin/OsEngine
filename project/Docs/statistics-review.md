# Ревью реализации статистики

Дата: 2026-09-18. Основание: ADR-0001, принятый до реализации.

## Проверено по коду

- MainWindow: кнопка в заданном месте, RU/EN, парольная блокировка, один owned
  modeless экземпляр, восстановление минимизированного окна, очистка ссылки.
  Запуск статистики не изменяет режим приложения, не запускает торговлю.
- Каталог: отдельный read-only адаптер, текущие/старые Settings, только реальные
  итоговые свечные файлы; нет создания OsDataSet, loaders и записи в датасет.
- Расчёт: точный merge по времени; A−B, volume>0 на обеих ногах; daily volume
  по полной выбранной истории ноги до join; coverage intersection/union;
  включительные пороги; разрывы дат не маскируются одним ликвидным интервалом.
- Итоги считаются по всем допущенным точкам, не как среднее дневных средних.
  Stddev — N, устойчивый сдвиг перед double; среднее — decimal running mean.
  Нулевому количеству точек соответствует null summary, не фиктивные нули.
- UI: параметры фиксируются перед worker; одна задача; отмена и закрытие
  не публикуют результат; обе ноги удерживаются FileShare.Read на весь анализ.
  Таблицы виртуальные, полный набор строк; тексты/темы штатные, обработчики
  именованные и отписываются. Исходная история не изменяется.

## Найдено и исправлено в ходе ревью

1. DataGridFactory по умолчанию отключает полосы прокрутки. Явно выставлены Both.
2. Штатный ToDecimal может некорректный ввод превратить в ноль. Перед ним добавлены
   лексическая и числовая проверки; дата проверяется, изменение текста инвалидирует результат.
3. Между проверкой shutdown Dispatcher и Invoke возможна гонка. Ошибка доставки
   обработана внутри DispatchCompletion и не выходит во вторую неперехваченную задачу.
4. Modeless окно остаётся открытым при смене темы/языка главного меню. Добавлены
   обновление заголовков/палитры таблиц, динамический цвет текста, отписки.
5. Склеенный парсинг даты/времени мог принять неправильное разделение колонок.
   Добавлены отдельные проверки длины DATE=8 и TIME=6.
6. Сумма смещений могла переполнить decimal при представимом среднем. Заменена
   на running mean; тестируются большие уровни и маленькие изменения на них.
7. Одного предварительно отменённого token недостаточно для теста отмены.
   Добавлены отмена внутри итерации, превышение лимита и освобождение файла после ошибки.

## Фактический статус проверок в среде разработки

- `git diff --check` — успешно.
- XML-парсинг нового окна, MainWindow и тестового csproj — успешно;
  дублирующихся имён элементов не найдено.
- Проверены объявления всех 36 тестовых сценариев автономного runner.
- `dotnet build project/OsEngine.sln` — не выполнен: `dotnet: command not found`.
- `dotnet run --project project/Tests/Statistics/OsEngine.Statistics.Tests.csproj`
  — не выполнен по той же причине. **36 сценариев написаны, но локально не пройдены.**
- Windows/WPF UI на реальном датасете не запускался: среда Linux без .NET SDK.
- Добавлен Windows CI: `.github/workflows/statistics.yml`, запуск тестов затем
  сборка решения на push ветки `feature/statistics-pair-analysis` или вручную.
  Наличие workflow не означает, что Actions включены или сборка уже прошла.
- MCP-стенд, торговые серверы и реальные подключения не запускались.

## Итог

Блокирующих замечаний при статическом ревью не осталось. До признания первой
версии проверенной необходим успешный запуск C#-тестов/сборки на Windows и
ручная приёмка из `statistics.md`. Эти проверки нельзя заменить чтением кода.
Первый релиз — табличный анализ Close-спреда, не график и не торговый робот.

## Расширение исследования пар (ADR-0002)

Следующий этап добавляет каталог серий по префиксам, четыре согласованные
области графика, SMA, статистику отклонений/возвратов и сортировку таблиц.
Архитектурное решение и независимое ревью реализации находятся в
`adr/0002-pair-research.md` и `adr/0002-pair-research-review.md`.

В ходе статического ревью исправлены потеря изображения на разрывах,
конфликт текстов с разделителями локализации, тяжёлая агрегация эпизодов
в UI и принятие произвольных суффиксов за код экспирации. Чтением проверены
расчёты, связь окон, снимки параметров, отмена, блокировка файлов и очистка.
Новые тесты находятся в `Tests/Statistics/ResearchTests.cs`.

В этой среде C#-тесты и сборка по-прежнему не запускаются из-за отсутствия
.NET SDK; Windows-поведение не проверено. Синтаксический разбор C# и XML,
проверка локализованных строк и `git diff --check` не заменяют эти проверки.
Опубликованный код следует проверить штатным workflow и ручной приёмкой.
