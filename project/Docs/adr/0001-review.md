# ADR-0001 — Архитектурное ревью

Дата: 2026-09-18.
Объект: [0001-offline-pair-statistics.md](0001-offline-pair-statistics.md).
Решение: **Accepted for implementation**. Блокирующих архитектурных замечаний
после уточнений ниже нет. Это разрешение реализации, не подтверждение её
корректности и не результат сборки или тестов.

## Проверено

- Анализируются только исходники форка `2Rukin/OsEngine`.
- Прочитаны `project/AGENTS.md`, карта проекта, coding guidelines и контексты
  пар/фьючерсов, индексов/спредов, архитектуры роботов и тем.
- `OsDataSet` запускает worker в конструкторе, а `SecurityToLoad.Load`
  вызывает `ActivateLoaders`. Отказ от их использования для read-only чтения
  принципиально необходим, несмотря на внешнее сходство с задачей импорта.
- Точка подключения ограничена главным меню; офлайн-анализ не создаёт
  торговые табы, соединения или заявки. Reader и ядро переиспользуемы отдельно
  от UI для будущей статистики одиночных и парных инструментов.

## Замечания и решения

| Риск | Решение в ADR | Статус |
|---|---|---|
| Close-спред принять за исполнимый арбитраж либо истинный внутрисвечной экстремум | Явные caveats, запрещён HighA−LowB, метрика ограничена Close | Закрыто |
| Объёмный фильтр выдать за доказанную ликвидность | Явный proxy, настраиваемые демонстрационные пороги, нет bid/ask-гарантий | Закрыто |
| Coverage искусственно повысить предварительным inner join | Intersection/union активных timestamp; дневные объёмы считаются до синхронизации | Закрыто |
| Неоднозначность порогов и пустой выборки | Включительные сравнения, диапазоны параметров, минимум одна общая активная точка | Закрыто |
| Неверные агрегаты разных дней | Невзвешенное среднее всех принятых точек и population stddev с делителем N | Закрыто |
| Склеить неизвестный пропуск с ликвидной историей | Разрыв при пропуске календарной даты, включая выходные | Закрыто |
| Потеря отрицательных цен | Разрешены; проверяется согласованность OHLC | Закрыто |
| Настройки перенесённого датасета направят чтение в другой каталог | Выбранная папка определяет корень; запрет выхода через имена Settings | Закрыто |
| Изменение входа или неожиданные фоновые загрузчики | Собственный read-only адаптер и запрет конкурентной записи во время чтения | Закрыто |
| Результат после закрытия/изменения параметров | Захват параметров, одна операция, отмена и проверка жизненного цикла | Закрыто |

## Контроль при ревью реализации

1. Проверить root containment и неоднозначные имена, старый/новый Settings,
   выбор только итоговых свечных файлов, сообщения с номером плохой строки.
2. Проверить отсутствие побочных записей и вызовов торгового/загрузочного
   жизненного цикла; логирование ошибок допускается отдельно от входных файлов.
3. На искусственных рядах проверить coverage, нулевые объёмы, включительные
   пороги, знак разности, отрицательные цены, одну/ноль точек, population stddev,
   разрывы и объединение итогов; не подменять это проверкой только UI.
4. Проверить отмену при чтении и расчёте, освобождение ресурсов, игнорирование
   результата закрытого окна, очистку устаревшего результата при новом запросе.
5. Проверить стиль проекта: XAML/code-behind, именованные обработчики,
   локализация без двоеточий/подчёркиваний внутри текста, DynamicResource,
   логирование исключений, отсутствие несогласованных async-методов.
6. Выполнить доступную сборку и тесты. Windows UI-проверка остаётся отдельным
   обязательством, если среда реализации не позволяет запустить WPF.

## Принятые ограничения

Нет нормализации контрактных множителей и валют, автосклейки экспираций,
календаря биржи, forward-fill и восстановления истинной внутрисвечной разности.
Наблюдаемые дневные объёмы не доказывают полноту файла. Одинаковый timestamp
свечей не доказывает одновременность последних сделок внутри интервала.
Дневной фильтр ретроспективный. Эти ограничения явно отражены в ADR и не
препятствуют первой версии описательной офлайн-статистики.
